Módulo de Identidade

Fluxo de autenticação recomendado

01
Lookup de Usuário
Consulta na tabela clients por e-mail ou username para resolver o e-mail real do Supabase Auth.
02
Handshake de Credenciais
Chamada ao auth.signInWithPassword. A sessão é persistida automaticamente pelo SDK.
03
Recuperação de Config
Carregamento do USER_CONFIG (local) baseado no user.id retornado pela sessão.
04
Sincronização Ativa
Disparo imediato do flush() da fila de persistência para processar itens pendentes.
