# Fase 2 — Avaliação e delimitação

Pré-condição: a Fase 1 deve estar documentada para este mesmo contato e projeto. Se o contato chegar com intenção direta de investir, a Fase 1 pode ser reconstruída retrospectivamente com evidências; não se registram reuniões fictícias.

## Avaliar
- Interesses, objetivos e restrições explicitados pelo colaborador.
- Necessidades reais e alternativas do projeto.
- Maturidade, dependências, custos, riscos e evidências disponíveis.
- Razões para priorizar, adiar ou rejeitar cada alternativa.

Saída: proposta de escopo fundamentada, lacunas explícitas e confirmação de alinhamento. Não presumir interesse, mandato ou compromisso.
